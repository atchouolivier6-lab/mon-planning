📖 Description

MC-Planning est une application gratuite de planification hebdomadaire créée par Olivier ATCHOU. Elle vous permet d'organiser vos tâches jour par jour avec des rappels automatiques.

🎯 Comment utiliser

1️⃣ Écrivez votre tâche dans le champ texte
2️⃣ Choisissez une heure de rappel (optionnel)
3️⃣ Sélectionnez le jour de la semaine
4️⃣ Appuyez sur ➕ Ajouter
5️⃣ Cliquez sur une tâche pour la barrer
6️⃣ Cliquez encore pour enlever la barre
7️⃣ 🗑️ pour supprimer une tâche
